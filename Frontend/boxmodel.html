CSS Module — Step 3

The CSS Box Model

Every HTML element is a rectangular box. Understanding its four layers — Content, Padding, Border, and Margin — is the foundation of all CSS layout.

Content Padding Border Margin

Visual Diagram

CONTENT
Content
The actual text, image, or element inside
Padding
Space between content and border (inside)
Border
The visible edge line around the element
Margin
Space outside the border (between elements)

The Four Layers Explained

📦 Content

The innermost area where text, images, or child elements live. Its size is set with width and height.

width: 300px;
height: auto;

🟩 Padding

Transparent space between the content and the border. Makes the element feel airy and readable. Padding is always inside the border.

padding: 1rem;
padding: 1rem 2rem;
padding-top: 0.5rem;

🔷 Border

A visible (or invisible) line wrapping around the padding. Defined by width, style, and color. A border adds to the total element size.

border: 2px solid #fff;
border-radius: 12px;
border-left: 4px solid blue;

🟡 Margin

Transparent space outside the border, pushing other elements away. Margins of adjacent elements can collapse into one.

margin: 1rem auto;
margin-bottom: 2rem;
margin: 0;

📝 CSS Syntax

/* Box Model shorthand: TOP  RIGHT  BOTTOM  LEFT (clockwise) */

.card {
  /* Width of the content area */
  width: 300px;

  /* Padding: same on all 4 sides */
  padding: 1.5rem;

  /* Padding: top/bottom  left/right (2 values) */
  padding: 1rem 2rem;

  /* Padding: top  right  bottom  left (4 values) */
  padding: 0.5rem 1.5rem 2rem 1rem;

  /* Border: size  style  color */
  border: 2px solid rgba(79, 140, 255, 0.5);
  border-radius: 12px;

  /* Margin: auto horizontally = centered in parent */
  margin: 1rem auto;
}

/* box-sizing: border-box — padding + border are INCLUDED in width */
/* (This is set globally in style.css with * { box-sizing: border-box; }) */
* {
  box-sizing: border-box;
}

🧪 Practice: 3 Cards with Different Spacing

Same HTML structure, different CSS box model values — notice how spacing changes the feel entirely.

Card A — Compact

Small Padding

Tight spacing works well for dense data-heavy UIs like tables or dashboards where space is at a premium.

padding: 1rem · border: 3px solid · margin: 0.5rem
Card B — Comfortable

Generous Padding

More breathing room makes content easier to read and gives a premium feel — great for feature cards and landing pages.

padding: 2rem 2.5rem · border: 1px solid · margin: 1.5rem
Card C — Asymmetric

Different Per Side

Padding and border can be set individually for each side — useful for accent effects, highlights, and creative layouts.

padding: 0.5rem 1.5rem 2rem 1rem
border-left: 4px · border-bottom: 4px

⚠️ Common Mistakes

/* ❌ MISTAKE 1: Forgetting box-sizing — padding adds to width unexpectedly */
.card { width: 300px; padding: 20px; } /* actual width = 340px! */

/* ✅ FIX: Use box-sizing: border-box globally (already done in style.css) */
* { box-sizing: border-box; } /* width stays 300px */

/* ❌ MISTAKE 2: Using margin for inner spacing */
.card h3 { margin-left: 20px; } /* use padding on .card instead */

/* ❌ MISTAKE 3: Margin collapsing confusion */
/* Two vertical margins of 20px don't add to 40px — they collapse to 20px! */
.section-a { margin-bottom: 20px; }
.section-b { margin-top: 20px; }
/* Gap between them = 20px, not 40px */

🎯 Interview Question

What is the difference between padding and margin? And what does box-sizing: border-box do?

Answer

Padding is space inside the border — it pushes content away from the edge and takes the element's background color.

Margin is space outside the border — it pushes other elements away and is always transparent.

box-sizing: border-box changes how width/height is calculated. By default (content-box), padding and border are added on top of the declared width. With border-box, padding and border are included inside the declared width — making layouts much more predictable.
