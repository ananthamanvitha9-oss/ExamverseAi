Module 7

HTML Tables

The <table> element organises data into rows and columns. Learn the anatomy: <thead> <tbody> <tfoot> <tr> <th> <td>

Table Tags Explained

Tag Full Name What It Does
<table> Table The root wrapper for the entire table structure.
<thead> Table Head Groups the header row(s). Typically contains column labels.
<tbody> Table Body Groups the main data rows of the table.
<tfoot> Table Footer Groups footer rows — used for totals, summaries, or notes.
<tr> Table Row Defines a single horizontal row inside thead, tbody, or tfoot.
<th> Table Header Cell A header cell — bold by default. Tells the browser this is a column label.
<td> Table Data Cell A regular data cell — holds the actual data value in a row.
