2. Formatting Elements

This is a standard Paragraph (p) element.
Using a Line Break (br) tag breaks this paragraph onto a new line without adding margins.

We can apply text emphasizing styles: this text is Strongly Bolded (strong), and this text is Emphasized / Italicized (em).

We also support scientific notations: - Superscript: 210 = 1024
- Subscript: Water is represented as H2O.
