Step 4: CSS Flexbox

Master 1-dimensional layouts using Flexbox properties: display: flex, justify-content, align-items, gap, and flex-direction.

display: flex

Defines a flex container and transforms all direct children into flexible items.

justify-content

Aligns items along the main horizontal axis: space-between, center, flex-start.

align-items

Aligns flex items along the vertical cross axis: center, flex-end, stretch.

gap

Sets consistent spacing between flex items without applying outer margins.

flex-direction

Specifies main axis direction: row (default horizontal) or column (vertical).
