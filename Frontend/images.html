HTML Image Element

Everything you need to know about using images in HTML — the <img> tag and its key attributes.

Key Attributes of <img>

Attribute What it does Example
src The path or URL of the image to display. Without this, no image is shown. src="./images/logo.jpg"
alt Alternative text shown when the image cannot load. Critical for accessibility (screen readers) and SEO. alt="ExamVerse AI Logo"
width Sets the display width of the image in pixels. Prevents layout shift while image loads. width="200"
height Sets the display height of the image in pixels. Use both width and height together to avoid content jumping on page load. height="50"

Example 1 — Full Size Logo (natural width)

No width/height set — uses the image's natural pixel dimensions.

Example 2 — Resized with width="300" height="75"

Setting explicit pixel dimensions scales the image in the browser.

Example 3 — Thumbnail (width="100" height="25")

The same image, shrunk to thumbnail size. The alt text remains important — if the image fails, browsers show the alt text instead.
