# ExamVerse AI

ExamVerse AI is a concept landing page for an AI-powered learning platform designed for Indian competitive exam aspirants.

## Project Structure

- Frontend/
- Backend/
- Database/
- Design/
- Documents/
- Assets/
- API/
- Testing/
- Deployment/

## Run locally

Open [index.html](index.html) in a browser, or serve the folder with any static server.

Example:

```bash
python -m http.server 3000
```

Then visit <http://localhost:3000/>
