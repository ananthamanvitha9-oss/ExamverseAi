# Examverse AI - System Design Document

## 1. Overview
Examverse AI is a comprehensive EdTech platform designed for competitive exam preparation (UPSC, SSC, Banking, etc.).

## 2. Architecture
- **Frontend:** React.js (Vite)
- **Backend:** Laravel (PHP)
- **Database:** MySQL
- **AI Integration:** LLM API (OpenAI / Gemini)
- **Mobile:** React Native (Expo)

## 3. Core Modules
- Authentication (Sanctum)
- Student Dashboard
- Course Management System (Video & PDF)
- Mock Test Engine (Timed Exams)
- AI Tutor (Live Chat)
- Current Affairs (News Engine)
- Admin Panel (CMS)
- Monetization (Payment Gateway)
